# cool-portfolioi-template

> The official portfolio starter for **[coolestdesigner.com](https://coolestdesigner.com)** — launch a polished designer portfolio in minutes.

## ✨ Features
- ⚡ Fast React + TypeScript + Tailwind CSS setup
- 🎨 Minimal, typography-first design
- 🎬 Fullscreen showreel intro
- 🧩 One config file for your name, role and projects
- 🔍 SEO and social sharing tags built in
- 📱 Looks great on phones and desktops

## 🚀 Getting started
```bash
git clone https://github.com/<your-username>/cool-portfolioi-template.git
cd cool-portfolioi-template
bun install
bun run dev
```
Open http://localhost:8080 and click **Enter portfolio** to preview your showreel.

## 🛠 Customize
All content lives in `src/data/portfolio.ts`:
- `name`, `role`, `location`, `tagline`
- `showreel` — your intro video
- `projects` — your case studies

## 🌐 Deploy
Works with any modern static/edge host. Build with `bun run build`.
